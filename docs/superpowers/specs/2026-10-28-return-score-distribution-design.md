# 返却用・得点分布票

状態：2026-10-28、配置見本・補足仕様・実装計画・追加の印刷修正をユーザーが承認。各タスクの実装と独立レビュー済み。最終確認・公開判断待ち。

## 目的と範囲

返却用の個別練習プリントに、小さな得点分布票を添える。児童が自分の得点と集団の分布を確認でき、既存の課題欄はそのまま使えるようにする。答案表面、採点結果、名簿、PDF画像、バックアップ形式は変更しない。他の児童の氏名・個別得点・順位は分布票に掲載しない。

## 比較した配置と承認済みの選択

- ４線を短くして分布票の場所を空ける案：重ならないが、練習欄の形が変わり、分布票の存在感も強い。
- **採用：４線を変更せず、白い小さな票を右下に重ねる。** ユーザーは文字と行間をさらに詰めた最終見本を確認し、この配置での実装を指示した。４線の右端が票に隠れるのは意図した表示であり、行数・出題数・用紙のページ数は票のために変えない。

## 見た目

最終見本 `return-distribution-placement.html` を基準とする。白地、細い灰褐色の枠、ごく薄い影。見本のA4縦では用紙幅の約30%、高さは用紙幅の約19.5%。550px幅の表示で約164×107px、本文約8.5px、行間1.12相当。小さな表示でも見本と同様、用紙と票を一緒に縮小し、モバイル用に票だけ拡大したりレイアウトを変えたりしない。

「得点分布」「クラス／学年・○人」「あなた ○点」「平均 ○点」、棒グラフ、凡例「棒：人数　線：あなた」を表示。通常の棒は灰色、本人の得点帯はテーマカラー #FCCC8E、本人の得点位置は縦線と点で示す。文字・グラフは印刷時にも鮮明なHTML/SVGを使用し、新しい画像生成や外部サービスは使用しない。

## 補足仕様（実装側の提案）

- 「2ページ目・個別課題」に「得点分布票を付ける」チェックボックスを追加し、初期値はオン。オフにすると従来どおり分布票なしで出力できる。
- 既存の「集計範囲」のクラス／同学年を分布票にも適用し、選択欄に得点分布も対象であることを明記する。返却対象の児童のチェックを減らしても、集計母集団は変えない。
- 採点が完了した児童の得点を集計し、欠席・未採点・採点途中は除外する。０点と部分点は正しく含める。既存のクラス／同学年の判定方法を利用する。
- 満点までを10等分した得点帯とし、実際の配点の単位で表示する。100点満点専用にはしない。各境界値は右の帯、満点だけは最後の帯に含め、１人を重複計上しない。平均点は必要に応じ小数第１位までとする。
- 集計対象が０人の場合は「採点完了データなし」と表示する。本人が採点途中の場合は本人得点・マーカーを表示せず「あなた —点」とする。不正な数値をNaNや無限値のグラフとして出力しない。
- 課題が続きのページを持つ場合、分布票は最初の課題ページだけに付ける。全問正解で課題がない児童にも、その課題面に分布票を付ける。両面印刷のページ順と調整用白紙は従来のまま。
- A4・B5・A5、縦・横に対応する。右下の既存余白内に収め、用紙幅30%を目安に最大幅63mmとする。問題の説明欄と手本の先頭は隠さない。

## 実装と確認の制約

既存のブラウザーJavaScript、HTML/CSS、Node/Playwrightの構成に追加する。新しい実行時依存関係、ネットワークサービス、保存データの移行は不要。新規ファイルを作る場合はオフライン利用に含める。

合成した非個人データで、集計範囲、０点・満点・部分点、境界値、未採点者除外、対象者ゼロ、表示オフをテストする。A4/B5/A5の縦横、異なる表裏の向き、課題の複数ページで、プレビューと実際のPDFを確認する。票をオン・オフしても４線の長さ、課題配置、出力ページ数が変わらないことを確認する。

「△の問題も含める」の初期値オンはローカルで実装・確認済み（187be6f）。手動で外したチェックを勝手に戻さず、この変更と併せて次の更新へ含める。GitHub公開は、実装と検証の完了後に別途確認する。

## 追加承認：返却PDFの本文縮小の修正

2026-10-28、合成PDFの目視確認で、表面が横向き・裏面が縦向きのとき、MediaBoxの用紙寸法は正しいのに本文と４線が小さくなる既存症状を発見した。今回の分布票オン／オフと実装前のHTMLで同じ出力座標になり、分布票が原因ではないことを確認済み。原因そのものはまだ未確定であり、ブラウザーの制限と断定しない。

ユーザーは「今回一緒に修正する」を明示的に選択した。この更新内で原因を特定し、選択した用紙サイズ・向きに対して答案画像と課題面を意図した実寸で出力する。PDFの外形だけでなく、本文・４線・分布票の出力上の寸法を検証する。A4/B5/A5、表裏の異なる向きと同じ向き、答案の用紙に合わせる／原寸左上配置、既存の両面順を保つ。プリンタードライバーの設定を変更する機能や任意倍率の補償機能は追加せず、採点・名簿・元PDFには触れない。

調査結果：最初の合成見本には25問に対し10枠という不整合があり、これだけでは通常の異方向印刷の不具合を証明できなかった。見本は正しい枠数へ修正した。一方、正常な10行3列の答案でも、スキャン端を越える有効な未クリップ補正座標によって本文が縮小することを実際のPDFで再現した。枠外の子要素が印刷全体の縮小判定へ影響しないよう、寸法指定済みの答案画像レイヤーへ印刷時だけ`contain:size`を追加した。生の補正座標や見えている採点記号は維持する。単純な全体拡大やPDFエンジン変更は行わない。
