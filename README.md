# YUTORI

YUTORIのGitHub Pages公開用リポジトリです。

- 公開ファイル: `index.html`
- バージョン: v0.3.52（ローカル検証候補・公開は別途承認後）
- 新しいテストでは「単語」と「英作文・和訳」を選べます。単語を10問1列にすると解答欄は用紙の左半分、20問2列では同じ半幅欄を2列で表示し、採点時も実際の解答欄だけを読み取ります。既存テストは従来どおり全幅です。
- 問題入力では、問題・模範解答の2列を貼り付ける通常方式と、問題別紙・模範解答のみ1列を貼り付ける方式を選べます。案内文・入力例・用紙の表示・読み取り範囲が連動します。
- 問題別紙の方式は問題番号のみを用紙に表示し、各マスの内側全体を読み取ります。選択はテスト・採点データに保存され、既存データは従来の方式のままです。
- 問題別紙の採点タイルは、読み取った画像の縦横比に合わせて高さを変え、横幅いっぱいに解答を表示します。
- 答案上部の出席番号マークを読み取り、登録名簿へ自動で割り当てます。
- 答案PDFはブラウザ内で処理され、端末の外へ送信されません。
- 採点済み答案への赤字加筆と、間違えた問題を使った個別練習課題を返却用PDFとして保存できます。
- 返却用PDFは、表面A4横・裏面A4縦のように向きが異なる場合も、各ページを選択どおりの実寸で作成します。
- 個別練習課題では、4線に合わせたRuRiRu Fontのグレーの手本を表示します。文字数で縮小せず、長い手本は続きの4線行へ折り返します。
- 個別練習課題の初期値は縦15問・横7問で、用紙の残り高さを使って1枚に収まるよう配置します。長い手本は複数行分として調整し、問題数は自由入力や自動最大数へのリセットもできます。1問だけで1枚を超える手本や手動指定時は、手本を切らず続きのページを作成します。
- PDF表示にはPDF.js（Apache License 2.0）を同梱しています。

## A5の印刷と答案の読み取り

A5は初期設定で、同じテストをA4用紙に2枚並べて印刷します。A5縦はA4横、A5横はA4縦になり、編集画面のプレビューは1枚のままです。A5を1枚ずつ印刷する設定も選べます。A4・B5の印刷は従来どおりです。

YUTORIが作るA4ページをそのまま印刷してください。プリンター側の「2ページを1枚」「2-in-1」などを重ねて指定すると、さらに縮小されます。プリンターの余白や倍率設定はYUTORIから制御できないため、試し刷りで確認してください。印刷後はA4を切り分け、児童生徒1人のA5答案がPDFの1ページになるようスキャンします。切り分け前の2人分の答案を自動分割する機能はありません。

答案の見出しと解答枠を基準に、通常の印刷縮小や位置ずれに合わせて採点画像と返却時の赤字を配置します。補正できる場合の採点画像は、手書きの文字を切らないよう問題文も含むマスの内側全体を、元の縦横比で表示します。見出しなどが検出できない場合は従来の読み取り方法を使います。任意の倍率、傷みのある答案、写真の遠近変形をすべて補正するものではなく、OCRによる採点ではありません。児童生徒への割り当てや採点結果を補正処理が変更することはありません。

一度オンラインで更新を読み込んだ後は、用紙の配置補正に必要な部品もオフラインで利用できます。

## 全データのバックアップ

ヘッダーの「バックアップ保存」または設定の「バックアップ設定」から、テスト、設定・クラス・名簿、採点途中と採点結果、読み込んだ元の答案PDF、ページ画像をひとつの `.yutori` ファイルに保存できます。バックアップはボタンを押したときだけ作成します。定期的な自動バックアップや、YUTORIによるクラウド同期はありません。

初回は保存先を選びます。通常の初期ファイル名は `YUTORI_全データバックアップ.yutori` です。

- 学校管理のChromebookでは、Google ドライブを通常の保存先にしてください。学校の設定でUSBが無効になっている場合、USBは利用できません。YUTORIは制限の解除や回避を行いません。
- Windowsなどその他の端末のChrome／Edgeでは、Google ドライブの同期領域、または端末から書き込み可能で利用が許可されたUSBメモリを選べます。

対応するブラウザでは選んだファイルをこのブラウザに記憶し、次回は同じファイルを上書きします。ブラウザの再起動などで保存権限の確認が表示された場合は、同じファイルへの書き込みを許可してください。「保存先を変更」から選び直すこともできます。保存先が未接続、移動・削除済み、書き込み不可の場合は保存を中止します。Google ドライブやUSBを再接続して再試行するか、保存先を選び直してください。自動的にダウンロード先へ切り替えることはありません。

ヘッダーのボタンにマウスを合わせるかキーボードでフォーカスすると、最後に保存・検証に成功した日時とファイル名が表示されます。同じ情報と保存したファイルの容量を「バックアップ設定」で確認でき、タッチ操作でも利用できます。未作成のときはその旨を表示します。完全な保存先パスは表示しません。後の保存に失敗しても、前回の成功日時・ファイル名・容量は更新されません。

「保存完了」は、選んだファイルへの書き込みと、そのファイルを読み戻して内容・バイト列を検証できたことを意味します。Google ドライブのクラウド同期完了を意味しません。別端末で利用する前に、Google ドライブ側の同期状況も確認してください。

`.yutori` は氏名・名簿・答案PDF・採点結果などの個人情報を含み、暗号化されていません。学校の管理方針に従って保管・移動し、共有範囲を確認してください。バックアップの内容はYUTORIから外部送信されず、ブラウザ内で処理されます。保存先やその権限はバックアップに含まれないため、別端末では保存先を改めて設定します。

## バックアップから復元

復元は現在のYUTORIデータをすべて置き換えます。データの追加・統合は行いません。復元元のファイルと、復元前の安全用バックアップを残して作業してください。他のYUTORIタブを閉じ、PDFの読み込みや採点作業が終わってから行います。

1. 「バックアップ設定」から「バックアップから復元」を押し、移した `.yutori` ファイルを選びます。
2. ファイル全体の検査が終わると、作成日時、作成元バージョン、容量、テスト・クラス・採点・元PDF・ページ画像の件数が表示されます。内容を確認してください。破損、不完全、非対応のファイルでは置き換えを開始しません。
3. 「復元前バックアップを保存」で、現在のデータを復元元・通常の保存先とは別のファイルへ保存します。初期ファイル名は `YUTORI_復元前バックアップ_YYYYMMDD_HHmm.yutori`（日時は端末の時刻）です。この別の安全用ファイルの保存と検証は必須です。失敗・キャンセル時は復元できません。
4. 保存と検証の成功後、「現在のデータがすべて置き換わることを確認しました」をチェックし、「全データを置き換えて復元」を押します。完了後は再読み込みされます。

同じファイルへの上書きに対応しないブラウザでは、通常のバックアップは毎回ダウンロードします。ダウンロード先と保存したファイルを自分で確認してください。復元元は通常のファイル選択から指定できます。復元前の安全用ファイルもダウンロードした後、「ダウンロードした安全用ファイルを確認」からそのファイルを選び直し、実際に保存された内容の検証を終える必要があります。ブラウザが末尾に番号を付けて名前を変更した場合は、案内された初期ファイル名へ戻して選んでください。選び直しと確認チェックが終わるまで全置換はできません。

復元が途中で中断した場合は、次回起動時にデータを確認して復元を完了するか、元の状態へ戻します。回復画面が出たら表示の案内に従ってください。「復元前バックアップを選んで回復」では、その復元の直前に保存した安全用ファイルを選びます。別のバックアップでは回復できません。他のタブがデータを使用しているという案内が出た場合は、他のYUTORIタブを閉じて再読み込みしてください。回復が終わるまでブラウザのサイトデータを削除せず、復元元と安全用ファイルを保持してください。

一度オンラインで更新を読み込んだ後は、バックアップ画面と処理をオフラインでも利用できます。保存先のGoogle ドライブやUSBが利用できるかどうかは端末側の状態によります。
