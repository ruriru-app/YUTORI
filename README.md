# YUTORI

YUTORIのGitHub Pages公開用リポジトリです。

- 公開ファイル: `index.html`
- バージョン: v0.3.47
- 問題入力では、問題・模範解答の2列を貼り付ける通常方式と、問題別紙・模範解答のみ1列を貼り付ける方式を選べます。案内文・入力例・用紙の表示・読み取り範囲が連動します。
- 問題別紙の方式は問題番号のみを用紙に表示し、各マスの内側全体を読み取ります。選択はテスト・採点データに保存され、既存データは従来の方式のままです。
- 答案上部の出席番号マークを読み取り、登録名簿へ自動で割り当てます。
- 答案PDFはブラウザ内で処理され、端末の外へ送信されません。
- 採点済み答案への赤字加筆と、間違えた問題を使った個別練習課題を返却用PDFとして保存できます。
- 個別練習課題では、4線に合わせたRuRiRu Fontのグレーの手本を表示します。文字数で縮小せず、長い手本は続きの4線行へ折り返します。
- PDF表示にはPDF.js（Apache License 2.0）を同梱しています。
